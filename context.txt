I am writing a research paper on using conditional normalizing flows to perform cosmological parameter inference from the statistical properties of cosmic voids, and I need your help drafting, editing, and refining the manuscript — so please absorb all of the following context before responding.

The scientific goal is to infer the five ΛCDM cosmological parameters (Omega_m, Omega_b, h, n_s, sigma_8) from summary statistics of the void population in a simulation box, using the Quijote N-body simulation suite as the training data. Each of the 1999 (one is missing due to the file not being found) Quijote simulations was run at a different point in a Latin hypercube over the 5-dimensional cosmological parameter space (stored in latin_hypercube_params.txt), so each simulation provides a paired (cosmology, void catalog) example.

The void catalogs come from VIDE-style outputs: for every simulation I read a "shapes" file (void_id, ellipticity) and a "centers" file (void_id, effective radius, density contrast, plus positional info), merge them on void_id in extract.py, and produce a per-simulation CSV of individual voids with three properties — density_contrast, radius, and ellipticity. Because per-void inputs are variable-length and unordered, I summarize each simulation's void population as three 1-D probability-normalized histograms with 18 bins each. The bin edges are global (shared across all simulations) and are computed in bins.py by pooling every void from every simulation and taking the 0.5th and 99.5th percentiles as the lower and upper edges of each property's range (percentile clipping removes extreme tails so the bins are informative for the bulk of the distribution). Each simulation is thus represented by a (18 × 3) array of normalized histogram values saved to BinnedData/simulation_{i}_binned.csv, with columns densitycontrast, radius, ellipticity. Simulation 1897 is missing and is skipped throughout.

The machine-learning pipeline lives in flow.py and is built with Pyro. I support four "modes": densitycontrast only (input dim 18), radius only (18), ellipticity only (18), and "combined" which concatenates all three histograms into a 54-dim vector — the combined mode is the headline result because it uses all three void summary statistics jointly. The input X is the histogram vector (dim 18 or 54) and the target Y is the 5-dim cosmological parameter vector. Both X and Y are standardized with sklearn StandardScaler (fit on the full dataset before splitting), and the data is split deterministically 70/15/15 into train/validation/test using a fixed seed (SEED=45).

The model is a conditional spline normalizing flow. Specifically, I factor the joint as p(X, Y) = p(X) · p(Y | X): the marginal over the context X is modeled by a TransformedDistribution built from a standard Normal base and N_CONTEXT_LAYERS = 1 spline_autoregressive transform, and the conditional p(Y | X) is a ConditionalTransformedDistribution built from a standard 5-D Normal base with N_CONDITIONAL_LAYERS = 4 conditional_spline_autoregressive transforms (bound=5), each conditioned on X. Training minimizes the negative joint log-likelihood -(log p(X) + log p(Y | X)) with Adam at learning rate 7e-4, up to 1000 steps, with early stopping (patience = 50 validation-loss evaluations) and restoration of the best-validation-loss weights.

At inference time, for each test simulation's histogram vector x, I draw 1000 posterior samples from p(Y | x), inverse-transform them through the y-scaler, and report the posterior mean and standard deviation for each of the 5 cosmological parameters. Evaluation produces per-parameter true-vs-predicted error-bar plots and four metrics: R² (coefficient of determination on posterior means), RMSE (on standardized-space but reported in physical units after inverse-transform), χ² = mean of ((true − pred_mean)² / pred_std²) which should be ≈ 1 if the posterior widths are well-calibrated, and MMRE (mean magnitude of relative error). Checkpoints, loss curves, per-parameter scatter plots, and a metrics CSV are saved per mode under checkpoints/<mode>/.

On the combined mode (all three void summary statistics), the current test-set results are: Omega_m R²=0.806, RMSE=0.052, χ²=1.33, MMRE=15.7%; sigma_8 R²=0.823, RMSE=0.050, χ²=0.63, MMRE=5.1%; n_s R²=0.193, RMSE=0.099, χ²=1.44, MMRE=8.0%; h R²=0.030, RMSE=0.111, χ²=1.06, MMRE=14.7%; and Omega_b R²=−0.040, RMSE=0.012, χ²=1.12, MMRE=23.2%. In other words, the void histograms carry strong information about Omega_m and sigma_8 (the parameters that most directly set the abundance, size, and shape of voids), modest information about n_s, and essentially no information about h or Omega_b given this summary and this sample size — which is consistent with physical expectations since voids are primarily sensitive to the late-time matter clustering amplitude and matter density. The χ² values are all near 1, indicating the flow's posterior widths are reasonably calibrated rather than overconfident or underconfident.
